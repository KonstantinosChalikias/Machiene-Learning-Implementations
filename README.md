# Advanced Methods of Machine Learning – Projects

This repository contains a collection of projects completed as part of the **Advanced Methods of Machine Learning** course. The projects explore fundamental concepts and practical applications of modern machine learning and deep learning techniques.

The topics covered include:

- **Neural Networks:** Exploring neural network architectures, their components, and how they are used to solve machine learning problems.
- **Backpropagation:** Understanding and implementing the backpropagation algorithm to train neural networks through gradient-based optimization.
- **Autoencoders:** Applying deep learning frameworks to build and train autoencoders for representation learning, dimensionality reduction, and data reconstruction.
- **Graph Neural Networks (GNNs):** Exploring graph-based deep learning methods and applying GNN architectures to learn from structured, relational data.

Each project reflects a different aspect of modern machine learning, from understanding the foundations of neural networks to working with more advanced architectures such as autoencoders and graph neural networks.
